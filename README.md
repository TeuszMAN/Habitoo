## Sobre o Projeto

**Habitoo** é um aplicativo em desenvolvimento baseado nos artigos dos [8 Rémedios Naturais](https://www.adventistas.org/pt/saude/8-remedios-naturais/). Seguimos as implementações sugeridas pelo padrão do formulário Q8RN para criar o app. Sua funcionalidade serve para ajudar pessoas a melhorarem sua saúde através de habitos cotidianos saúdaveis e o nosso projeto visa coleta dados e devolver informações e feedbacks ao usuário de maneira simples e eficaz. Foi desenvolvido em Flutter, usando como banco de dados SQLite.

## Começando

### Pré-requisitos

- Flutter SDK
- Emulador

### Instalação

```bash
#Clone o repositório
git clone https://github.com/TeuszMAN/Habitoo.git
cd Habitoo

#Instale as depêndecias do flutter (necessário ter configurado o ambiente)
flutter pub get
flutter run

# Voce pode criar o apk
flutter build apk --release
```
